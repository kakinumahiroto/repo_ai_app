# AI家庭教師アプリ 要件定義書

## 1. 対象と目的

| 項目     | 内容                             |
| ------ | ------------------------------ |
| 対象ユーザー | 小学生〜高校生のうち、勉強があまり得意でない層        |
| 利用者層   | 生徒本人、保護者、オンライン家庭教師の補助ツールとしての活用 |
| 主な用途   | 自習時間や家庭教師が対応できない時間帯での学習補助      |
| 対象教科   | 数学・英語（将来的に理科・社会・国語も対応予定）       |
| テスト運用  | 妹・弟での先行試験、将来的には知人の塾経由などで一般展開   |

---

## 2. 機能要件（学習者向け）

| 区分     | 機能内容                                       |
| ------ | ------------------------------------------ |
| 質問入力   | テキスト／画像OCR／音声入力による質問投稿                     |
| 回答出力   | GPT-4oによるヒント・考え方・段階的説明の提示（直接的な答えは避ける）      |
| 学年設定   | 学年またはレベルの選択により難易度・表現を調整                    |
| 誘導設計   | 「この問題がわからない」などの曖昧な質問を具体化するプロンプト誘導設計        |
| 学習履歴保存 | Firestoreを用いた質問履歴・フィードバック履歴の記録             |
| 入力支援   | 画像OCR（Tesseract.js）／音声認識（Web Speech API）対応 |
| 出力制御   | 「答えだけ教えて」といった問いに対し、段階的ヒントや考え方のみを提示         |
| 質問回数制限 | 月次での質問回数上限機能（管理者による個別設定・付与機能含む）             |

---

## 3. 機能要件（保護者・管理者向け）

| 区分       | 機能内容                               |
| -------- | ---------------------------------- |
| 学習ログ閲覧   | 学習履歴・進捗を保護者が確認できるダッシュボード（将来的実装）    |
| レポート自動生成 | 学習傾向・改善点のPDFまたはWebレポート（自動で作成・共有）   |
| アクセス制御   | アカウントごとに生徒・保護者・講師を識別し表示範囲を制限（想定段階） |
| 質問回数管理   | 各ユーザーの月次質問回数制限設定・付与・リセット機能（管理者専用） |

---

## 4. 非機能要件・UX

| 観点        | 内容                                 |
| --------- | ---------------------------------- |
| 操作性       | 音声・画像でも操作できる直感的なUI（スマホでも快適）        |
| 丁寧な応答     | GPT応答はわかりやすく・丁寧語を用い、いきなり答えを提示しない   |
| 安全設計      | 間違った情報を避けるように「検討の余地がある」等の補足含めて返答する |
| 導入ガイド／ヘルプ | 学習者が質問しやすいよう「例」を表示し、初めてでも使えるようにする  |

---

## 5. セキュリティと運用

| 項目              | 内容                                        |
| --------------- | ----------------------------------------- |
| 認証方式            | Firebase Authentication（匿名 or Googleログイン） |
| データ保存           | Firestore（個人特定情報を除外した匿名ベース設計）             |
| 通信セキュリティ        | HTTPS強制、APIキーはバックエンドで安全に保管                |
| Firestore Rules | ログインユーザーごとの読み書き制限                         |
| 利用ログ管理          | Firestoreにて学習ログ・アクセスログを記録（保護者向けレポートに活用）   |

---

## 6. 収益化・料金設計（将来的展望）

| 項目     | 内容                                             |
| ------ | ---------------------------------------------- |
| 損益分岐点  | 月額500円 × 5人程度で黒字ライン（Firebase + GPT API従量課金ベース） |
| 料金モデル  | 月額制、回数制限付きフリープラン、保護者向けレポート課金モデルなど              |
| 無料提供範囲 | 広告付き or 機能制限ありのライト版提供                          |

---

## 7. 拡張構想・今後の展開

| 項目     | 内容                              |
| ------ | ------------------------------- |
| 科目拡張   | 理科・社会・国語の対応（GPTの得意分野も加味）        |
| 自動学習分析 | 質問傾向・弱点分析・成長傾向の可視化（教師・保護者に提示）   |
| アプリ展開  | PWA化またはExpoを用いたiOS/Androidアプリ展開 |
| B2B展開  | 小規模塾や家庭教師グループ向けの導入支援パッケージとして商品化 |
