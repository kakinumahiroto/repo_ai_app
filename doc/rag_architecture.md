以下は、「Firestore → RAG抽出 → GPTへ渡す」までの\*\*AI家庭教師アプリにおける会話履歴RAGコンテキスト化フロー図（データフロー）\*\*です。

---

# ✅ 会話履歴コンテキスト化フロー（RAG + Chat Completion）

```
┌────────────────────────────┐
│      生徒の質問            │
│   例：「√2の意味は？」       │
└────────────┬────────────┘
             │
             ▼
┌────────────────────────────┐
│     Firestore から会話履歴を取得    │
│ - user_id 単位で取得（最新10件）      │
│ - role: user/assistant               │
└────────────┬────────────┘
             │
             ▼
┌────────────────────────────┐
│   LangChain + GPT でRAG抽出     │
│ - StuffDocumentsChainを使用       │
│ - Prompt：「重要な発言を抽出せよ」  │
│ - LLM: ChatOpenAI (gpt-3.5)        │
└────────────┬────────────┘
             │
             ▼
┌────────────────────────────┐
│   抽出された要点を system に埋め込む │
│  例：                           │
│  「この会話では平方根の意味に関心がある」 │
└────────────┬────────────┘
             │
             ▼
┌────────────────────────────┐
│   Chat Completion API を呼び出す   │
│ - model: gpt-4o                    │
│ - message構成：                   │
│   system: 要点                     │
│   user: 現在の質問                  │
└────────────┬────────────┘
             │
             ▼
┌────────────────────────────┐
│      GPT-4o の回答生成         │
└────────────────────────────┘
```

---

## 🔧 実装上のポイント

| 処理フェーズ         | 実装技術                                              |
| -------------- | ------------------------------------------------- |
| Firestore 履歴取得 | `firebase_admin.firestore`                        |
| 要点抽出（RAG）      | `LangChain + ChatOpenAI`                          |
| GPT連携          | `openai.ChatCompletion.create()`                  |
| セキュリティ         | - Firestore rules<br>- APIキーはCloud Functions経由    |
| 履歴データ構成        | `{ role: 'user' or 'assistant', content: '...' }` |

---

## ✏️ 応用アイデア

* `summary_cache` をFirestoreに保存（毎回再要約を避ける）
* `topics` を自動分類し、履歴から関係あるテーマだけ抽出
* 質問のたびに履歴再利用 → 学習ログの蓄積にもつながる
