# AI家庭教師アプリ「SeLf」 要件定義書

## 1. 対象と目的

| 項目     | 内容                             |
| ------ | ------------------------------ |
| 対象ユーザー | 小学生〜高校生のうち、勉強があまり得意でない層        |
| 利用者層   | 生徒本人、保護者、オンライン家庭教師の補助ツールとしての活用 |
| 主な用途   | 自習時間や家庭教師が対応できない時間帯での学習補助      |
| 対象教科   | 数学・英語・理科・社会・国語（全教科対応済み）       |
| テスト運用  | 妹・弟での先行試験、将来的には知人の塾経由などで一般展開   |

---

## 2. 機能要件（学習者向け）

| 区分     | 機能内容                                       |
| ------ | ------------------------------------------ |
| 質問入力   | テキスト／画像アップロード／音声入力（Web Speech API）による質問投稿                     |
| 回答出力   | GPT-4oによるヒント・考え方・段階的説明の提示（直接的な答えは避ける）      |
| 学年設定   | 小学生・中学生・高校生の選択により難易度・表現・口調を調整                    |
| 個人化対応   | ニックネーム設定・苦手科目登録による個別最適化プロンプト        |
| 学習履歴保存 | Firestoreを用いた質問履歴・スレッド式会話履歴の記録             |
| 入力支援   | 画像アップロード／音声認識（Web Speech API）対応、数式LaTeX表示対応 |
| 出力制御   | 「答えだけ教えて」といった問いに対し、段階的ヒントや考え方のみを提示         |
| 質問回数制限 | 月次での質問回数上限機能（管理者による個別設定・付与・リセット機能含む）             |
| 追加質問機能 | 同一スレッド内での連続的な質問・回答によるインタラクティブ学習             |
| 科目別最適化 | 数学（LaTeX数式）・英語・理科・社会・国語それぞれに特化したプロンプト設計             |

---

## 3. 機能要件（保護者・管理者向け）

| 区分       | 機能内容                               |
| -------- | ---------------------------------- |
| 管理者機能   | 各ユーザーの月次質問回数制限設定・付与・リセット機能（AdminUsageManager実装済み） |
| プロフィール管理 | ニックネーム・学年・苦手科目の設定・編集機能（ProfileView実装済み）    |
| 学習ログ閲覧   | 学習履歴・進捗を保護者が確認できるダッシュボード（将来的実装）    |
| レポート自動生成 | 学習傾向・改善点のPDFまたはWebレポート（自動で作成・共有）   |
| アクセス制御   | アカウントごとに生徒・保護者・講師を識別し表示範囲を制限（想定段階） |
| お問い合わせ機能 | ContactForm実装済み、Cloud Functions経由でのメール送信対応 |

---

## 4. 非機能要件・UX

| 観点        | 内容                                 |
| --------- | ---------------------------------- |
| 操作性       | 音声・画像でも操作できる直感的なUI（スマホでも快適）        |
| 丁寧な応答     | GPT応答はわかりやすく・丁寧語を用い、段階的ヒントを提示   |
| 安全設計      | 間違った情報を避けるように「検討の余地がある」等の補足含めて返答する |
| 導入ガイド／ヘルプ | 学習者が質問しやすいよう「例」を表示し、初めてでも使えるようにする  |
| レスポンシブデザイン | PC・タブレット・スマートフォン全対応のレスポンシブUI実装済み |
| アクセシビリティ | カラーコントラスト・フォントサイズ・操作しやすいボタン配置に配慮 |

---

## 5. セキュリティと運用

| 項目              | 内容                                        |
| --------------- | ----------------------------------------- |
| 認証方式            | Firebase Authentication（メールアドレス・パスワード認証） |
| reCAPTCHA v3対応 | スパム・自動化攻撃防止のためのreCAPTCHA v3実装済み |
| 多要素認証          | SMS・メール・認証アプリによる2段階認証（実装予定） |
| ログイン試行制限      | 連続ログイン失敗時のアカウントロック機能（実装予定） |
| データ保存           | Firestore（個人特定情報を除外した匿名ベース設計）             |
| 通信セキュリティ        | HTTPS強制、APIキーはバックエンドで安全に保管                |
| Firestore Rules | ログインユーザーごとの読み書き制限実装済み |
| 利用ログ管理          | Firestoreにて学習ログ・アクセスログを記録（保護者向けレポートに活用）   |
| パスワードポリシー      | 8文字以上、英数字記号混在の強固なパスワード要求実装済み |

| UI/UX | LaTeX数式表示（KaTeX） | 数学問題の美しい表示 |
